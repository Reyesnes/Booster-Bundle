# Content, Ads & Strategy Rules

- Check `content/brand-voice.md` before writing any customer-facing copy (ads, social, emails). If it's still marked as a stub, ask the owner for tone/voice direction before producing final copy — don't invent a voice.
- Prefer the installed content/ads skills over freehand copywriting: `ad-copy` for paid ad variations, `omnipresence-content-engine` for multi-platform content calendars/carousels, `ugc-prompt-engine-booster-bundle` for UGC-style video prompts, `affiliate-program` for affiliate/referral structures.
- File new content under the matching subfolder: `content/ads/`, `content/social/`, `content/calendar/`. Strategic docs (roadmap, OKRs, positioning) go under `strategy/`.
- Strategy docs should stay dated and let git track history rather than being silently overwritten — note major pivots at the top of the file instead of deleting prior reasoning outright.
